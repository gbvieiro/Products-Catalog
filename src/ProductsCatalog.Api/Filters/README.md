# Filters

Reservado para Action/Result Filters do ASP.NET Core (ex: um filtro de
autorizacao por Role, rate limiting, ou um `ApiExceptionFilterAttribute`
alternativo a `Middleware/ExceptionHandlingMiddleware.cs`). Nenhum filtro
foi necessario ainda porque o middleware de excecao ja cobre o caso de uso
atual - a pasta fica aqui para quando esse dia chegar.
